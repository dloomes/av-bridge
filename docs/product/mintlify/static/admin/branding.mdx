Branding changes how the portal looks for everyone in your organisation, and how your sign-in page looks before anyone signs in. Changes apply as soon as you save. You need the **Update branding** permission, which the admin role includes.

## Portal

| Setting | What it does |
|---|---|
| **Product name** | Replaces "M.A.R.C.U.S." in the header and browser tab. The sign-in page then reads "*Your name* on M.A.R.C.U.S.". Leave blank for the default. |
| **Accent colour** | Colour for buttons, links and highlights. |
| **Logo** | PNG, JPEG or SVG, up to 256 KB. Shown in the sidebar and page headers. |

## Sign-in page

Your organisation has its own sign-in address. Ask your service provider for it if you don't have it.

| Setting | What it does |
|---|---|
| **Welcome message** | A short line under the heading, such as who the portal is for or who to contact. Up to 500 characters. |
| **Support contact** | An email address or web link, shown as "Need help?" under the form. |
| **SSO button label** | Replaces the "Sign in with Microsoft" text, when Microsoft sign-in is set up. |
| **Hero background image** | PNG, JPEG, SVG or WebP, up to 1 MB. Fills the left half of the sign-in page on wide screens. |

## Sign-in policy

**Require single sign-on** turns off passwords so that everyone signs in with Microsoft. It's only available once Microsoft sign-in is set up for your organisation. See [Sign-in with Microsoft](/admin/single-sign-on#require-microsoft-sign-in) before using it.

## Preview and save

The **Preview** card shows the current branding. Select **Save changes**; the sidebar, headers and browser tab update straight away.

<Tip>
For the clearest logo, use an SVG, or a PNG with a transparent background at least 200 pixels wide.
</Tip>
