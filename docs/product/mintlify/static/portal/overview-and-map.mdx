**Overview** and **Map** show your whole estate on one screen. Both refresh every 15 seconds; select **Refresh** to update straight away.

## Overview

### Summary cards

The cards at the top count your devices by status, and your rooms. Select a card to open the matching list.

| Card | Shows | Opens |
|---|---|---|
| **Total devices** | Every device | All devices |
| **Online** | Devices responding normally | Online devices |
| **Offline** | Devices that have stopped responding | Offline devices |
| **Unknown** | Devices whose status can't currently be checked, usually because their Collector isn't reporting | Unknown devices |
| **Switched off** | Shown only overnight: devices [Room Readiness](/portal/room-readiness) has switched off for the night | Switched-off devices |
| **Rooms** | Every room | — |
| **Rooms with issues** | Rooms with at least one offline device | The offline devices |
| **Open alerts** | Alerts not yet resolved. Reads **Open alerts (critical)** when any is critical | [Alerts](/portal/alerts) |
| **Offline collectors** | Collectors that have stopped checking in | Collectors |

### Buildings

Below the cards, each building has a tile showing its location, device count, a health bar, and how many devices are offline, unknown, switched off and online. Select a tile to list that building's devices.

Devices that aren't in a building appear in an **Unassigned** tile.

## Map

The map shows a pin for each building that has devices, coloured by its worst device status: red if anything is offline, grey if anything is unknown, blue if devices are switched off for the night, green if all is well. The number on a pin is its device count.

Select a pin to see the building's address and status, then **View devices** to list them.

Buildings that haven't been given map coordinates are listed under **Missing coordinates**. An administrator can add them on the **Locations** page.

## Device status

| Status | Meaning |
|---|---|
| **Online** | The device is responding normally. |
| **Offline** | The device has stopped responding. An alert is raised. |
| **Unknown** | M.A.R.C.U.S. can't currently check the device. |
| **Switched off** | [Room Readiness](/portal/room-readiness) switched the device off for the night. It returns to its usual status after the morning warm-up. No alert is raised. |
| **Collector offline** | The device's status is unknown because the Collector that monitors it has stopped reporting. Fix the Collector and its devices' statuses return. |

<Tip>
Make **Overview** or **Map** your landing page with **Set as default** in the page header. Only these two can be your landing page.
</Tip>
