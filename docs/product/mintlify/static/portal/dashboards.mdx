A dashboard is your own page of widgets: open alerts, rooms that need attention, last night's Room Readiness results, room usage and more, laid out in the order you want. Go to **Dashboards** in the sidebar.

Everyone can build dashboards for themselves. Administrators can also share dashboards with the whole organisation, such as a wall screen for the service desk.

## Create a dashboard

1. Go to **Dashboards** and select **New dashboard**.
2. Give it a **Name**.
3. Leave **Start with suggested widgets** ticked to begin with estate status, rooms needing attention, Room Readiness, open alerts and room usage. Untick it to start empty.
4. Select **Create**.

The dashboard you last opened opens next time you come to **Dashboards**. Switch between dashboards with the list at the top.

## Arrange widgets

1. Select **Edit**.
2. Select **Add widget** and choose one. Widgets that show one room or one device ask which.
3. Drag a widget by its handle to move it. With the keyboard, focus the handle, press Space, use the arrow keys, then press Space again.
4. Choose each widget's size: **Small**, **Medium**, **Large** or **Full width**. On a phone every widget is full width; on a tablet, small and medium widgets sit two to a row.
5. Select a widget's settings button to change what it shows, or its cross to remove it.
6. Select **Save**, or **Cancel** to leave the dashboard as it was.

Widgets refresh on their own, every 30 seconds for live information and less often for reports.

## Widgets

| Widget | Shows | Settings |
|---|---|---|
| **Estate status** | Devices online, offline, unknown and switched off. Select a number to list those devices. | Building |
| **Open alerts** | The newest open alerts, with their device. | Severity, how many |
| **Rooms needing attention** | Rooms with devices offline or not reporting, worst first. | Building, how many |
| **Room Readiness, last 24 hours** | Runs passed, failed and running, and the rooms that failed with the reason. | Power schedule, readiness checks or both; how many |
| **Room usage** | The busiest or least-used rooms, in hours a day. Uses the same calls and people counts as the **Room usage** report under **Reports**. | Busiest or least used, period, how many |
| **Lowest uptime** | The devices with the lowest uptime. | Period, how many |
| **Collectors** | Collectors online, and any that aren't with when they were last seen. | |
| **Warranty** | Assets out of warranty, and those expiring within 90 days. | How many |
| **Firmware** | Devices on and off their target firmware version. | How many |
| **Room** | Every device in one room with its status and power state. | Room |
| **Device** | One device's status and its latest readings. | Device |
| **Recent activity** | The latest changes and commands from the activity log. | How many |
| **Rooms in use now** | Rooms in a call or with people in them right now, from codecs and people-counting cameras. | How many |
| **Building status** | Every building as a tile: green when all is well, amber when devices aren't reporting, red when any are offline. | Region |
| **Map** | Buildings on a map, coloured by status, as on the **Map** page. | |
| **Big number** | One figure in large type: devices offline or not reporting, open or critical alerts, rooms needing attention, Room Readiness failures, Collectors not online, or rooms in use now. It turns red once it reaches the number you set. | Figure, red from, label |
| **Clock** | The time and date. | Time zone, 12- or 24-hour, seconds |
| **Notice** | A message you write, such as a change freeze or a room out of use, styled as information, a warning or critical. | Message, style |

Each widget only shows what your access allows. If your access is limited to some rooms, widgets only show those rooms. A widget whose information you can't see, such as **Recent activity** without the **View audit log** permission, says so.

## Show a dashboard on a wall screen

Select **Display** on a dashboard to open it full screen in a new tab: dark, with larger text for viewing across a room, and a clock. Select **Full screen** to fill the screen; it shows when you move the mouse. The cursor hides after a few seconds, and the layout moves by a few pixels every five minutes so nothing burns into the screen.

If the screen stops getting updates, for example because its network drops, a red banner across the top says since when.

**Display** uses your own sign-in, so the screen stops when you sign out or your session ends. For a screen that stays on, use a display link.

### Display links

A display link shows one or more shared dashboards on a screen with no one signed in, rotating between them. You need the **Share dashboards** permission.

1. Go to **Dashboards** and select **Display links**.
2. Give the link a **Name**, such as the screen's location.
3. Tick the shared dashboards to show, in the order you want them. With more than one, choose how long to show each.
4. Select **Create display link**, then **Copy** the address. It's shown only once.
5. Open the address in the screen's browser.

A display link can only view: it can't change anything, can't see the activity log, and sees no more of the estate than the person who created it. Anyone with the address can see those dashboards, so treat it like a password. The list of display links shows when each screen was last seen.

To stop a screen, select **Revoke**. It stops updating at once and says the link has been revoked. If you stop sharing a dashboard, it's taken off every display link straight away.

Creating and revoking display links is recorded in the activity log.

## Share a dashboard

You need the **Share dashboards** permission, which administrators have.

- To publish one of your dashboards, open it and select **Share**. To make a shared dashboard yours again, select **Stop sharing**.
- To create one already shared, tick **Share with everyone in the organisation** under **New dashboard**.

Shared dashboards are listed first, under **Shared with everyone**. Everyone in the organisation can view them, but only people with **Share dashboards** can change, rename or delete them. Anyone can select **Copy** to make their own copy and change that.

Sharing a dashboard shares its layout, not its information. Each person sees the widgets filled in with what their own access allows.

Creating, changing, sharing and deleting dashboards is recorded in the activity log.
