MM.A.R.C.U.S. Collector

Small Linux or Windows host you provide, sited on the AV VLAN. One outbound HTTPS connection to M.A.R.C.U.S. Cloud. Local status & touch-panel proxy on TCP 8080 — LAN only, never internet-facing.

Security & data assurance

  • UK-hosted exclusively — all data stored and processed in AWS London.
  • TLS 1.2+ on every connection to M.A.R.C.U.S. Cloud.
  • HMAC-signed Collector requests — identity verified per request.
  • Entra ID SSO — per-tenant access, MFA at your policy.
  • Scoped API tokens — revocable, expiring, least-privilege.
  • Row-level tenant isolation in the database.
  • No AV device exposed to the public internet.
