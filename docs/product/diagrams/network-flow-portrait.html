Security principles

  • Zero inbound firewall rules at any customer site.
  • TLS 1.2 minimum on every connection to the cloud; TLS 1.3 preferred.
  • HMAC-SHA256 signature on every Collector request — per-Collector key.
  • Row-level tenant isolation enforced by the database engine.
  • UK-hosted exclusively — all data in AWS London (eu-west-2).
